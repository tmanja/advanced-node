## Sobre o projeto

Este projeto faz parte do treinamento **Advanced Node.js**, ministrado pelo professor [Rodrigo Manguinho (Mango)](https://github.com/rmanguinho), disponível na Udemy.

O objetivo do treinamento é demonstrar como desenvolver uma API com arquitetura bem definida e desacoplada, utilizando **TDD (Test-Driven Development)** como metodologia de desenvolvimento e **Clean Architecture** para distribuir responsabilidades em diferentes camadas.

Durante o desenvolvimento, são aplicados os princípios do **SOLID**, além de Design Patterns e boas práticas de programação para solucionar problemas recorrentes no desenvolvimento de software.

## Princípios

Os princípios e práticas utilizados no projeto incluem:

- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)
- Separation of Concerns (SoC)
- Don't Repeat Yourself (DRY)
- You Aren't Gonna Need It (YAGNI)
- Keep It Simple (KISS)
- Composition Over Inheritance
- Small Commits

## Objetivos de aprendizagem

Ao acompanhar o projeto, os principais objetivos são:

- Desenvolver APIs com Node.js e TypeScript.
- Aplicar Clean Architecture na organização do código.
- Utilizar TDD para orientar o desenvolvimento.
- Compreender e aplicar os princípios SOLID.
- Identificar e eliminar Code Smells por meio de refatoração.
- Aplicar Design Patterns em problemas reais.
- Desenvolver aplicações desacopladas, testáveis e de fácil manutenção.
